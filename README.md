# TeacherDox Muse — moved

This repository held early experiments for the Meta Global AI Developer Hackathon (2 – 3 Nov 2026).
It is **not** the submission and its contents were withdrawn:

- its evaluation table was simulated, not measured;
- its default model IDs were never verified against the Meta Model API;
- its `docs/` were design documents written before the hackathon.

The hackathon work, with measured results from real runs, lives in
**[sandeepkumareeri/teacherdox-core](https://github.com/sandeepkumareeri/teacherdox-core)**:
the open `.tdx` 2.0 teaching record, the Record Engine on SAM 3.1, Muse Voice Transcribe, Muse Spark
and Muse Spark Open, the verifiable trust layer, and the eval in
[`eval/RESULTS.md`](https://github.com/sandeepkumareeri/teacherdox-core/blob/main/eval/RESULTS.md).

The earlier files remain in this repository's git history.
